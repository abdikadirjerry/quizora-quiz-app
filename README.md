# Quizora — Interactive Quiz & Trivia Platform

Quizora is an interactive quiz and trivia application designed to make learning fun through timed challenges, multiple-choice questions, category-based quizzes, and personalized performance tracking.

The project is being developed as a portfolio application to demonstrate practical frontend development skills, reusable React components, responsive UI design, and clean JavaScript fundamentals.

## Features

- Interactive multiple-choice quizzes
- Multiple quiz categories
- Difficulty selection
- Timed quiz challenges
- Question progress tracking
- Instant answer feedback
- Score calculation and performance summaries
- Answer review
- Quiz history
- Local leaderboard
- Responsive layouts for mobile, tablet, and desktop
- Accessible and intuitive user interface

Features will be implemented incrementally as the project develops.

## Technology Stack

- HTML5
- CSS3
- JavaScript ES6+
- React
- Vite
- Tailwind CSS
- React Router
- Lucide React
- Git and GitHub

## Getting Started

### Prerequisites

Install Node.js and npm before setting up the project.

### Installation

Clone the repository:

```bash
git clone https://github.com/abdikadirjerry/quizora-quiz-app.git
```

Navigate to the project directory:

```bash
cd quizora-quiz-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

### Production Build

To generate a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Project Goals

The goal is to build a polished, maintainable, and accessible quiz application while practicing real-world frontend development workflows.

The project will prioritize readable code, reusable components, reliable quiz logic, responsive design, and meaningful version-control history.

## Development Status

**Current stage:** Initial project setup.

Features, documentation, and testing will be added as development progresses.
